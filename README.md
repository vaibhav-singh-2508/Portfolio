# Vaibhav Thakur — Portfolio

A retro-futuristic portfolio built with React.js + Vite.

## 🚀 Run Locally

```bash
npm install
npm run dev
```

## 🏗️ Build for Production

```bash
npm run build
```

## 🌐 Deploy Options

### Option 1 — Vercel (Recommended, FREE)
1. Push this folder to a GitHub repo
2. Go to https://vercel.com → "New Project"
3. Import your GitHub repo → Click "Deploy"
4. Done! Live in ~60 seconds ✅

### Option 2 — Netlify (FREE)
1. Run `npm run build` locally
2. Go to https://netlify.com → "Add new site" → "Deploy manually"
3. Drag & drop the `dist/` folder
4. Done! ✅

### Option 3 — GitHub Pages (FREE)
1. Install gh-pages: `npm install --save-dev gh-pages`
2. Add to package.json scripts: `"deploy": "gh-pages -d dist"`
3. Run: `npm run build && npm run deploy`

## ✏️ Customize
- Edit name, projects, skills, experience in `src/App.jsx`
- Update email/social links in the Contact section
- Swap placeholder project links with real GitHub/live URLs
